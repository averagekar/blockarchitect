# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The BlockArchitect team takes security seriously. If you discover a security vulnerability in BlockArchitect (including server vulnerabilities, API key leakage risks, or NBT parser exploits), please report it responsibly:

1. **Do NOT report security vulnerabilities via public GitHub Issues.**
2. Report vulnerabilities via private GitHub Advisory report under the repository's **Security** tab (`https://github.com/averagekar/blockarchitect/security/advisories/new`).
3. Include detailed steps to reproduce the issue, potential impact, and any suggested remediations.

We will acknowledge receipt within 48 hours and work on a patch promptly.
